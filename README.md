# 🔍 /rate for PokeIdle

Uma extensão independente para **PokeIdle.io** que faz a análise de eficiência de status, IVs e entrega o **veredito mastigado** da build, além de um preview de dano das habilidades.

---

## 🚀 Como Instalar no Navegador (Brave / Chrome / Edge)

1. Clique no botão verde **`Code`** no topo desta página e escolha **`Download ZIP`**.
2. Extraia o arquivo `.zip` em uma pasta no seu computador.
3. Abra o seu navegador e acesse a página de extensões:
   * **Brave:** `brave://extensions`
   * **Chrome:** `chrome://extensions`
   * **Edge:** `edge://extensions`
4. Ative a chave **"Modo do desenvolvedor"** *(Developer mode)* no canto superior direito.
5. Clique no botão **"Carregar sem compactação"** *(Load unpacked)*.
6. Selecione a pasta extraída da extensão.

---

## 🎯 Como Usar
1. Abra o [PokeIdle.io](https://pokeidle.io/).
2. Abra a ficha de qualquer Pokémon.
3. Clique no botão amarelo **`/rate Analisar Status`** no topo da ficha para ver o relatório completo.
